# Environment kit (Blender 5.2)

Every environment asset in `game/assets/environment/` is generated by these scripts — no third-party meshes.

```bash
# build everything, or only some assets / categories
blender -b --factory-startup --python tools/blender/environment/build_assets.py
blender -b --factory-startup --python tools/blender/environment/build_assets.py -- props crypt
blender -b --factory-startup --python tools/blender/environment/build_assets.py -- teleporter_platform throne

# EEVEE preview renders (consistent 3/4 camera + light rig) into work/lemondev/bh-001/evidence/environment/renders/
blender -b --factory-startup --python tools/blender/environment/render_assets.py -- [names...] [--res 512]
```

| File | Category | Contents |
|------|----------|----------|
| `assets_arch.py` | architecture | walls (straight, capped, corner, doorway, window, broken, **low cutaway**), pillars, arches, stairs, floor tile, beam, gate |
| `assets_nature.py` | nature | rocks, cliffs, rubble, trees, bushes, grass, fern, mushrooms, roots, logs, stumps |
| `assets_props.py` | props | breakables with fragments (crate, barrel, urn, statue_small), furniture, camp, storytelling props, cistern pieces (ladder, scaffold, dock, boat, winch) |
| `assets_crypt.py` | crypt, landmarks | statues, altar, sarcophagus, gravestones, teleporter dais (intact/destroyed), corrupted obelisk, ritual circle, bridges, ruined tower, temple facade, throne |
| `assets_town.py` | town | timber-framed house (intact/burnt), market stall, well, fountain, palisade and fences |

Conventions: metres, Blender Z-up exported as glTF Y-up (Blender −Y becomes Godot +Z, the "front"), origin at the
bottom centre unless noted, 4 m wall grid, material names from the `BH_*` contract (Godot swaps them for
`MaterialLibrary` materials), `<name>-colonly` collision children, child empties as sockets (`flame`, `light`,
`center`, `door_light`). Deterministic: each asset seeds its RNG from its name.
