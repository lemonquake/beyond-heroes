# Beyond Heroes character / weapon pipeline (C6)

Everything in `game/assets/characters/` and `game/assets/weapons/` is generated by these scripts (deterministic,
no manual edits, no third-party assets). Blender 5.2, Godot 4.7, system Python 3 with numpy + PIL.

## Regenerate

```sh
cd tools/blender/characters
# everything: 14 weapon GLBs, knight.glb, mage.glb, anim_meta.json, Blender re-import validation (~70 s)
blender -b --factory-startup --python build.py -- all
# partial targets (combine freely)
blender -b --factory-startup --python build.py -- weapons
blender -b --factory-startup --python build.py -- knight mage      # also rewrites anim_meta.json
blender -b --factory-startup --python build.py -- meta
blender -b --factory-startup --python build.py -- validate         # -> evidence/characters/validation.txt
# Godot import check on a throwaway project (never on game/); appends a section to validation.txt
python3 godot_check.py [--scratch /tmp/claude-0/c6] [--godot godot]
# evidence renders (EEVEE; headless Linux needs a virtual display) -> work/lemondev/bh-002/evidence/characters/
xvfb-run -a -s "-screen 0 1920x1080x24" blender -b --factory-startup --python render_evidence.py -- all
#   modes: heroes | weapons | attacks | loco | idles | reactions | casts ; options --res 1024 --cell 384 --char knight,mage
```

On Windows replace `blender` with `"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe"` and drop `xvfb-run`.
Scratch frames go to `$BH_SCRATCH/frames` (default `/tmp/claude-0/c6`); sheets are composed by `compose_sheets.py`
with `$BH_PYTHON` (default `python3`).

## Layout

| file | role |
|---|---|
| `build.py` | entry point / GLB export (30 fps, NLA track per action, Y-up) |
| `build_chars.py` | character registry (`CHARACTERS`) + assembly: body parts -> skinned mesh, armature, baked actions |
| `char_knight.py`, `char_mage.py` | per-hero modules: `PROPS`, `EXTRA_BONES`, `PALETTE`, `build(body)`, optional `secondary()` |
| `bh_skeleton.py` | shared skeleton (contract bone names, rest pose); proportions dict per character |
| `bh_body.py`, `bh_mesh.py` | modeling toolkit (model-space authoring in a relaxed pose, converted to T-pose rest) |
| `bh_materials.py` | contract material names `BH_*` + per-character palettes, baked vertex AO (`Col`) |
| `bh_anim.py`, `bh_math.py`, `bh_gait.py` | pose DSL, FK/IK evaluator, slide-free procedural gaits, action baker |
| `lib_*.py`, `bh_library.py` | the shared action library (117 clips) and the `anim_meta.json` writer (measured values) |
| `bh_diag.py` | measurements: foot contacts / ground speed / slide, weapon-tip sweep -> hit windows |
| `bh_weapons.py` | 14 weapon builders (origin at grip, +Z blade/shaft, flats +-Y, shield face -Y) |
| `validate.py`, `godot_check.py` | re-import checks (Blender / Godot) |
| `render_evidence.py`, `preview_chars.py`, `bh_render.py`, `compose_sheets.py` | evidence renders and contact sheets |

## Conventions the game relies on

* Clips are baked at 30 fps, in place (hips move vertically / small weight shifts only).
* `anim_meta.json` `hits` = frames where the weapon tip visibly sweeps its contact arc (tip speed >= 30 % of the
  strike peak, widened to >= 3 frames), measured on the evaluated skeleton; ground speeds are measured from planted
  sole points (`foot_slide_max` = worst deviation of a planted foot's velocity, m/s).
* Weapons attach to `weapon.R` / `weapon.L` with an identity transform (checked in Godot: socket +Y = blade forward,
  +Z = back of the hand).
* `*.glb.import` next to the hero GLBs set `nodes/use_name_suffixes=false`; without it Godot 4.7 strips the `_loop`
  suffix and `block_loop` imports as `block`.
* New characters: add `char_<name>.py` with the module interface above and register it in `build_chars.CHARACTERS`.
