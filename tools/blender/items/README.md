# Beyond Heroes item models (bh-006)

Every item base in the game has its own procedurally built model in `game/assets/items/<id>.glb` (165 models incl.
`gold_pile.glb`), generated by these scripts. Deterministic; no manual edits; no third-party assets.
Blender 5.2, Godot 4.7, system Python 3 with numpy + PIL. Reuses the modeling toolkit in `../characters/` (bh_mesh).

## Regenerate

```sh
# 1. dump the item list from the game (after adding or renaming bases in data_items.gd)
"C:/Users/Lemon PC/Desktop/Godot.exe" --headless --path game res://tests/tools/dump_items.tscn      # -> items.json
# 2. models (+ optional icon renders); optional ids restrict the run
"C:/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b --factory-startup --python build_items.py -- all
"C:/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b --factory-startup --python build_items.py -- models iron_longsword
# 3. game icons for the bases whose icon points at assets/ui/icons/items3d (new bh-006 items), and contact sheets
python icons_post.py game
python icons_post.py sheet my_sheet
# 4. re-import in Godot
"C:/Users/Lemon PC/Desktop/Godot.exe" --headless --path game --import
```

## Layout

| file | role |
|---|---|
| `item_kit.py` | palette materials (`MAT`: key -> base, colour, metal/rough, emission) exported as `BH_<base>__it_<key>` so Godot keeps each item's colours; shape helpers |
| `item_weapons.py` | 13 parametric weapon builders + `SPECS` (one spec per weapon base) |
| `item_gear.py` | shields, helms, hoods, circlet, chest pieces, leggings (`legs`, bh-024), gloves, boots, rings, amulets, charms + `GEAR` |
| `item_goods.py` | potions and bottles, scrolls, pouches, bombs, jars, tins, materials, quest items, gold pile + `GOODS` |
| `build_items.py` | registry lookup, GLB export (`../characters/build.export_glb`), studio icon renders |
| `icons_post.py` | 128 px game icons (dark radial backdrop + contact shadow, like the SVG item icons), contact sheets |
| `items.json` | the item list written by `game/tests/tools/dump_items.tscn` |

## Conventions the game relies on (`game/src/loot/item_models.gd`)

* Weapons: hand-socket convention of `../characters/bh_weapons.py` — origin at the grip, long axis +Z (Godot +Y), flats
  +-Y. They are also the held models (`Player.weapon_model_for`).
* Shields: handle at the origin, face -Y (Godot +Z). Chest pieces, inner garments, leggings and gloves: upright, front -Y.
  The game lays these (and weapons) flat when they lie on the ground.
* Everything else stands on its base at z = 0.
* A weapon's element (items.json `element`) adds a glowing inlay (`ELEMENT_GLOW`) unless the spec sets its own `glow`.
