--------------------------------------------------
MANDATORY DEVELOPMENT RULE
--------------------------------------------------

For every system you work on:

DESIGN IT.

IMPLEMENT IT.

RUN THE GAME.

TEST IT.

VERIFY THE DATA.

TEST EDGE CASES.

TEST IT WITH OTHER SYSTEMS.

FIX THE PROBLEMS.

RETEST IT.

POLISH IT.

DO NOT mark something complete just because code exists.

A system is complete only if it works correctly during actual gameplay.

Frequently inspect your own work.

Ask:

"Is this genuinely fun?"

"Does this system work correctly?"

"Does the UI correctly communicate the system?"

"Does this look like a finished RPG?"

"Are the numbers actually correct?"

"Can this system break when equipment, buffs, skills, talents, levels, statuses, and elements interact?"

"Would a player immediately understand what is happening?"

Whenever possible, create developer tests or debug panels to verify calculations.
