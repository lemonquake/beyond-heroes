# Void Rift (`void_rift`)
- Script `tools/blender/creatures/build_void_rift.py` -> `game/assets/characters/void_rift.glb` (+ `.glb.import`)
- Triangles: 3834 (core 3490, ring_1 132, ring_2 164, ring_3 48). Budget 6k.
- Size: 2.42 m tall overall, tear ~1.35 m wide, shard halo to +-1.3 m. Origin = tear centre; lowest point 1.23 m below the origin -> recommend float_hover ~1.35 so the bob (+-0.12 m) never dips into the floor.
- Nodes (Godot space, front = +Z):
  - `core` rot X-20 deg (top leans back so the 54 deg camera sees into it): jagged vesica tear; violet-black vortex funnel receding 0.36 m, 7 emissive violet/magenta spiral streaks into a glowing magenta eye, glowing magenta lip, jagged obsidian crust, 10 obsidian shards jutting from the rim. Game pulses its scale.
  - `ring_1` rot X70 deg (local up = the tear's front normal): 9 obsidian shards (3 with violet glow splinters) orbiting IN the tear's plane, r 0.85 m.
  - `ring_2` authored tilt X64/Y8 deg: 11 larger shards, r 1.15 m, a few degrees off the tear plane.
  - `ring_3` identity: 8 violet/magenta motes circling horizontally, r 0.8-1.3 m, height +-0.5 m.
- Palette (`__void_rift`): BH_Shadow void (0.02,0,0.04), BH_Emissive violet (0.62,0.25,1.0 x8), BH_Aether magenta (1.0,0.25,0.72 x6), BH_Horn glossy obsidian, BH_Stone violet-grey obsidian facets.
- Limitations: seen from behind it is a dark jagged disc (the vortex is one-sided); the swirl does not turn by itself (the game only scales `core`; a slow spin of `core` about its local Y axis = the tear normal would sell the vortex).
- Validation: scratch Godot 4.7.2 import (`tools/godot_check_floaters.py`, log `logs/godot_check.txt`): loads, 0 import errors, no skeleton / AnimationPlayer, all nodes and `BH_*__void_rift` materials present. Build log: `logs/build_void_rift.log`.
- Evidence: `void_rift_rest_iso.png` (gameplay camera 54 deg at 16 / 22 m 1:1 crops, back view, 2x zooms, 7 m), `void_rift_views.png` (4 side views, from-above view, close-up). Workbench renders: emissive materials show as flat bright colour (no bloom).
- Pipeline: `"<blender>" -b --factory-startup --python tools/blender/creatures/build_void_rift.py -- [--preview DIR]`; shared helpers in `tools/blender/creatures/kit_d13_float.py`. No clips (static; the game animates the nodes, see `character_visual.gd` `_animate_floating`).
