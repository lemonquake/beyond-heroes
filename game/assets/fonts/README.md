# Chat emoji font

Noto Emoji, from https://github.com/google/fonts/tree/main/ofl/notoemoji.
Downloaded 1 October 2026. `NotoEmoji-Regular.ttf` contains the upstream
`NotoEmoji[wght].ttf` variable font without modifications.

Used as a fallback for chat, speech bubbles and the emoji picker on systems
without an installed emoji font. Licensed under SIL OFL 1.1; see NotoEmoji-OFL.txt.
