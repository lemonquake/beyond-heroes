# Official icons

The official set uses painted dimensional subjects, dark blue-charcoal backgrounds, worn steel, leather and stone. Light comes from the upper left. Physical effects use silver and ochre; fire orange-white, ice cyan, lightning yellow-white, earth ochre, wind pale green, water blue, light gold, and dark magic violet. Subjects have safe margins and no embedded text, numbers or frames. The transparent Aether Forged border is a separate cosmetic overlay.

The live scan covers 1,630 item bases, 95 hero skills, 54 Tempo skills, 278 tree nodes, 111 visible statuses, class crests, attributes, elements, UI actions, signature traits and all 12 weapon upgrades. The set adds 519 painted icons and retains 1,536 distinct model-matching equipment/crystal PNG routes. Shared symbols remain valid for related talent upgrades, status effects and item bases; every active hero and Tempo skill has its own identity route, including the four previously unrelated hero aliases.

`UIArt` resolves artwork through `OfficialIcons` and `game/assets/ui/official/manifest.json`. `ItemBaseDef.icon_path()` applies the same redirects for inventories, belt slots, touch controls and tooltips. Original SVGs remain fallback assets. Tree side upgrades retain their authored symbols. Artwork loading is lazy and cached by the existing UI lookup; new textures use mipmaps, with smooth filtering local to icon controls.

Border texture, aperture, tint and style ID are independently configurable. See [Icon borders](ICON_BORDERS.md) for registration, replacement, fallback and saved-selection details. Future content must register only styles available to the player; no purchase or entitlement service is added by this artwork pass.

Originals and exact generation prompts are in `output/official-icons-20261027/sheets/` and `plan.json`. `registry.json` maps content to subjects. Reproduce packaging with `python tools/official_icons.py pack`, then `pack --check` and `audit`. Packaging only crops/resizes originals; it does not redraw them. Run Godot editor import after adding images. Mipmap settings are retained in the committed `.import` files. Generate a new dated run for future art changes and preserve accepted originals.

Runtime verification uses `test_official_icons` and `test_icon_borders` with the existing test runner. `official_icon_catalog.tscn -- --out=<absolute JSON>` exports current routes. `official_icon_capture.tscn -- --gallery=<absolute PNG> [--4k] [--scenario=gallery|skills|upgrades]` renders actual controls at 1920x1080 or 3840x2160 independent of monitor limits.

The large source regression run passed 29,186 checks. Final icon/border checks after filtering changes passed 11,384 checks with empty stderr. The broader run includes intentional corrupt-save warnings and shutdown resource warnings; this is not a clean-lifecycle or device-performance certification. A separate reviewer preferred the new project set over the old artwork; some busy combat compositions lose fine detail at 32 pixels. Physical Android display/input checks remain device work. Full evidence and build receipts are in `output/official-icons-20261027/` and the run handoff.

Release files are `build/windows/BeyondHeroes.exe` (Windows release) and `build/BeyondHeroes.apk` (ARMv7/ARM64, existing debug signing). Both were exported from an isolated archive of source commit `d1ca242801f1f527e3dc0d55ce858d794d4a9ce5`; unrelated local changes were excluded. `output/official-icons-20261027/builds.json` records SHA-256 hashes and checks. The Windows package passed 8,380 resource checks, and the APK passed its icon ZIP/CRC audit and signature verification. A direct Windows cold start rendered 360 gameplay frames and exited 0; its forced shutdown produced texture/RID/ObjectDB cleanup warnings documented in the handoff. Physical Android testing has not been run.
