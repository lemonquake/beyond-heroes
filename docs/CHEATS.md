# Beyond Heroes cheat codes

On desktop, press Enter to open chat, type one code and press Enter again. On touch controls, open Chat, enter the code and tap Send. Codes ignore capitalization and spaces at the beginning or end; enter the full code as one message.

Codes can be repeated. Rewards and point changes are kept by the normal save system. Item gifts add nothing if the entire gift will not fit. Skill, stat and talent points are separate pools.
