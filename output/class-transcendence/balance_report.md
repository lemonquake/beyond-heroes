# Class Transcendence balance

Source: `output/class-transcendence/balance.csv` from `tests/tools/transcend_balance.gd` (the bh-010 combat bot on Malasugue, 24 s fights, neutral dummies that never die). Every build of a family has the same gear (its starting bases made at the hero's level, Elite), the same attribute rule and the same skill/talent point budget. Changes are against the starting class at the same level. Damage, defense and sustain are listed separately; nothing is summed into one score. Kill-based traits (Dread, Soul Harvest, Collapse, Blood Price) do not fire on these dummies. Repeated runs vary by about 5-10 %.
